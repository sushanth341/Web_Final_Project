# Build a social media app 
> Build a social media app just like (instagram , facebook, twitter clone) with Node + React  + Bootstrap 4

## Install dependencies in app-social-media 
### npm install

## Install react-scripts dependencies for client
### cd client ---> npm install react-scripts

## "cd.." to exit the client module 

## Connection to mongo db info is alredy  added in .env

## Run the client & server with concurrently
### npm run dev

## To run only server
## Run the Express server only
### npm run server

## To run only client
## Run the React client only
### npm run client



### Server runs on http://localhost:5000 and client on http://localhost:3000
